UPLOAD TO GITHUB

1. Upload index.html, styles.css, app.js, and README.md to the root of your repository.
2. Commit the files to the main branch.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose main and / (root), then Save.

Open index.html locally first if you want to preview it. Excel import requires an internet connection because the spreadsheet reader is loaded from a public CDN.
